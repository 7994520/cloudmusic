# CloudMusic

个人练习项目仓库。

## 环境

- 编辑器：VSCodium 1.140
- 版本控制：Git 2.55
- 主要技术栈：Vue（Volar / ESLint / Prettier / Live Server）

## 目录

```
.
├── README.md
└── .gitignore
```

## 常用命令

```bash
git status              # 查看改动
git add .               # 暂存全部改动
git commit -m "说明"     # 提交
git push                # 推送到 GitHub
git pull                # 拉取远端更新
```

## 备注

第一次推送前需在 GitHub 网页上新建同名仓库 `CloudMusic`，然后关联远端：

```bash
git remote add origin https://github.com/7994520/CloudMusic.git
```
